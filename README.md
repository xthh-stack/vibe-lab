## 中文

Vibe Lab 用来收藏我通过 **Vibe Coding** 创作的作品。这里的项目可能源于一个突然冒出的想法、一次学习需求，或一个值得自动化的重复流程；我会借助 AI 快速探索、构建并持续打磨它们。

这个仓库不追求统一的技术栈或固定的作品形态。代码、工具、Agent Skill 和各种小实验都可能出现在这里。比起一开始就做到完美，我更在意先让想法真正运行起来，再从实际使用中发现更好的方向。

### 关于这个仓库

- **灵感驱动**：从真实兴趣和实际问题出发。
- **快速创造**：通过与 AI 协作，让想法尽快变成可运行的作品。
- **持续迭代**：作品会随着使用体验和新认知不断演进。
- **保持开放**：允许尝试不同技术、形式和解决路径。

部分项目仍处于实验阶段，目录结构、接口和使用方式可能随时调整。每个作品的具体说明请以其目录中的文档为准。

## English Version

Vibe Lab is a home for the things I create through **vibe coding**. A project might begin with a passing idea, a personal learning need, or a repetitive workflow worth automating. With AI as a creative collaborator, I explore these ideas, turn them into working artifacts, and refine them through real use.

There is no single tech stack or fixed format here. Code, tools, agent skills, and small experiments can all find a place in this repository. The goal is not to make every idea perfect from the start, but to make it real first—and then discover where it should go next.

### Current Projects

| Project | Description |
| --- | --- |
| [Finance Beginner](./skills/finance-beginner/) | A daily concept-learning workflow for Chinese-speaking finance beginners. |
| [Building PPT Study Quests](./skills/building-ppt-study-quests/) | Turns course materials into Obsidian notes, importance-rating pages, and offline learning quests. |
| [WeChat Draft Publisher](./skills/wechat-draft-publisher/) | A workflow for formatting, previewing, and uploading Markdown articles to WeChat Official Account drafts. |

More projects will be added as new ideas turn into experiments.

### About This Repository

- **Driven by curiosity**: Projects start with genuine interests and real problems.
- **Built quickly**: AI collaboration helps ideas become working creations sooner.
- **Improved continuously**: Each project evolves through use, feedback, and new understanding.
- **Open to exploration**: Different technologies, formats, and approaches are welcome.

Some projects are still experimental, so their structure, interfaces, and usage may change. Refer to the documentation inside each project directory for the most accurate details.
