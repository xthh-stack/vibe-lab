# 用户工作偏好

## 创建学习流水线类 Skill

- 默认采用轻量实现，目标是快速得到可用的个人 Skill，不按正式软件发布项目扩大工程规模。
- 优先复用已确认的笔记、HTML、题库和现有模板，不重新生成已完成文件。
- 只执行适用 Skill 规范要求的最低限度验证：一个轻量基线、必要的 2～3 个代表性场景、一次核心功能测试和安装后冒烟检查。
- 默认不制作复杂通过率报告，不开展多轮代理评审、重复浏览器测试、变异测试或多个产物版本。
- 只有用户明确要求严格评测，或核心测试暴露会直接影响使用的缺陷时，才扩大验证；扩大前先说明原因和预计新增工作。
- 用户要求“继续”时，从已有文件和报告的断点继续，不重做已完成部分。
