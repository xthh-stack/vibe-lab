# 初学金融 Skill

> [!abstract] 一句话说明
> 每次围绕一个清晰主题，讲解 **5 个彼此关联的金融概念**，把它们串成一条由浅入深的知识链；从全球金融市场中选择最有教学价值的近期事件，并在适合时加入历史对照，帮助金融投资新手理解“它是什么、为什么重要、如何影响投资判断”。

## 适用场景

当用户提出以下需求时使用本 Skill：

- “今天的 5 个金融概念”
- “继续我的金融入门学习”
- “围绕利率、ETF、估值等主题给我上一课”
- “结合最近市场讲几个金融概念”
- “从上次的学习进度继续，不要重复”

本 Skill 适用于**金融知识教育和投资框架学习**，不替代针对个人情况的投资、税务或法律建议。

## 学习目标

每次课程应帮助用户完成以下四件事：

1. 准确理解 5 个概念的定义。
2. 看懂 5 个概念之间的因果关系。
3. 知道这些概念会在哪些真实投资场景中出现。
4. 能用自己的话复述当天的知识链，并尝试应用到 ETF、股票、利率、国债或估值分析中。

## 核心规则

### 1. 每次固定讲 5 个概念

- 每次只选择 **5 个核心概念**。
- 不把同义词或一个概念的细小组成部分拆成多个概念来凑数。
- 如需解释辅助术语，可在正文中简短说明，但不得挤占 5 个核心概念的名额。

### 2. 五个概念组成连续知识链

优先选择存在明确递进或因果关系的概念，而不是罗列五个互不相关的名词。

推荐链条形式：

```text
前置条件 → 传导机制 → 资产影响 → 估值结果 → 投资应用
```

例如：

```text
政策利率 → 市场利率 → 债券价格 → 股票折现率 → 估值变化
```

讲解时必须明确说明：

- 前一个概念如何引出后一个概念；
- 中间通过什么机制发生影响；
- 哪些条件下这条关系可能变弱、反转或暂时失效。

### 3. 从基础到进阶，避免知识跳跃

- 优先从用户已知内容向外扩展，每次只提高一个难度台阶。
- 引入新概念前，先补齐必要的前置知识。
- 若用户没有提供学习记录，默认从最基础、最常用的概念开始。
- 若用户提供了历史记录，应避免重复已掌握的内容；如必须复习，应说明复习目的，并用新的关系或应用场景深化理解。

建议的长期学习路径：

```text
市场与资产基础
→ 收益、风险与复利
→ 股票、债券与 ETF
→ 利率与货币政策
→ 财务报表与公司质量
→ 估值与折现
→ 组合、相关性与资产配置
→ 市场周期、行为偏差与风险管理
```

### 4. 自动记录已学概念并主动去重

学习数据保存在独立文件 [[finance-learning-ledger|金融学习台账]] 中。本 Skill 只保存稳定规则，**不得把个人学习记录或已学概念写回本文件**。

每次生成新课程前，先读取学习台账，再确定当天的 5 个概念。

- 将概念名称统一为标准名称，并把常见别名、英文名和缩写视为同一概念。例如“市盈率”“Price-to-Earnings Ratio”“P/E”“PE”只算一个概念。
- 默认不再把台账中标记为“理解”或“可应用”的概念作为核心概念重复讲解。
- 标记为“初识”的概念可以在后续课程中深化，但必须换一个更高层次的关系或应用角度，并注明“复习深化”。
- 如果新知识必须依赖已学概念，可用 1～2 句话回顾，但该概念不占当天 5 个新概念名额。
- 用户主动要求复习时可以重复，但要说明本次复习目标，避免原样重讲。
- 同名异义或高度相似的概念，要先说明区别，再决定是否属于新知识点。

每课结束后，应更新学习台账：

1. 添加本课日期、主题和 5 个核心概念；
2. 为每个概念记录标准名称、别名、掌握程度和一句话理解；
3. 记录概念之间的知识链；
4. 记录仍有疑问和下一课建议；
5. 若能编辑文件，直接更新 `finance-learning-ledger.md`；若不能编辑文件，则在回答末尾输出一段可直接粘贴进该台账的 Markdown 记录块。

如果找不到学习台账：

- 先在本 Skill 同目录查找 `finance-learning-ledger.md`；
- 若有文件写入能力，则按本 Skill 的台账模板新建该文件；
- 若没有写入能力，则请用户提供台账内容，或把本课标记为“未读取历史记录”，不得假装已经完成去重。

> [!warning] 去重不等于永不复习
> 避免的是“无意义重复”。间隔复习、纠正误解、补充边界条件和从新场景深化，都属于有效学习，但必须清楚标记复习原因和新增理解。

### 5. 从全球市场选择最有教学价值的案例

案例选择不预设 A 股优先。生成课程前先观察与今日知识链相关的全球市场，包括：

- A 股、港股、美股、欧洲和日本等主要股票市场；
- 国债、信用债和货币市场；
- 利率、汇率、原油、黄金及其他重要商品；
- 主要央行政策、宏观数据和具有广泛影响的公司事件。

从中选择**一个教学价值最高的实时主案例**，而不是罗列多条新闻。优先选择因果链清楚、可靠数据充足、与当天概念直接相关、能帮助建立长期投资框架的事件。中国市场没有合适事件时，直接使用其他市场，不强行建立国内联系。

- 使用当天或近期公开事实，并写明**具体日期、市场状态、时区或数据截止点**。
- 涉及实时或近期数据时，先查证可靠来源，不得凭记忆编造点位、涨跌幅、政策决定或公司数据。
- 优先引用央行、统计机构、交易所、监管文件、公司公告或基金官网等一手来源；必要时补充 Reuters、AP 等可信媒体。
- 清楚区分“已确认事实”“基于事实的合理解释”和“仍不确定”。相关性或同时发生不等于唯一因果。
- 默认寻找一个与主案例或知识链直接相关的**历史金融市场案例**，用于解释机制、边界或相似现象的不同成因；没有自然关联时可以省略，不为完整而硬塞。
- 实时案例与历史案例都存在时，用短表格或几句话比较背景、传导机制、市场信号和结果。
- 不因央行提供流动性工具就直接判断政策宽松，也不因央行加息就推断其不会维护短期市场流动性。

### 6. 面向新手，定义准确，表达方式灵活

整节课程应让用户理解以下问题，但**不要求每个概念都使用相同的小标题逐项回答**：

- 它是什么；
- 为什么重要；
- 如何起作用；
- 在什么投资场景中出现；
- 有哪些重要误区或边界。

根据概念本身选择最合适的表达方式：机制型概念可用因果叙述，交易工具可用步骤或场景，数量概念可用公式和算例，相近概念可用对比表，历史变化可用时间线，抽象概念可用类比。五个概念的写法可以不同，避免机械重复“一句话定义、为什么重要、投资场景、常见误区”等固定栏目。

首次出现的缩写必须同时给出中文名、英文全称和缩写，例如：

> 市盈率（Price-to-Earnings Ratio，PE）

如使用公式，应先解释各变量和直觉，再展示公式。除非确有必要，一次课程不使用过多公式。

### 7. 强调关系和应用，而非背诵

讲完单个概念后，要把它接回知识链。优先使用以下投资语境：

- **ETF**：指数跟踪、费用、成分股、行业与地区暴露、持仓重叠；
- **股票**：盈利、现金流、估值、流通盘、市场预期；
- **利率与国债**：政策利率、收益率、期限、债券价格、风险偏好；
- **估值**：盈利、现金流、增长、折现率、安全边际；
- **组合管理**：仓位、相关性、集中度、波动与回撤。

不得把课程写成具体证券的买入或卖出指令。若用户要求分析某项投资，应清楚列出假设、风险和不确定性。

## 生成流程

每次生成课程时，依次完成以下判断：

1. **读取独立台账**：打开 [[finance-learning-ledger]]，识别已学概念、别名、掌握程度、近期疑问和偏好；不要从 Skill 正文推断个人学习进度。
2. **执行概念去重**：把候选概念与台账对照，排除同义词、缩写和无意义重复；必要复习须标注原因。
3. **选择今日主线**：用一句话确定今天要解决的问题。
4. **挑选 5 个概念**：检查是否由浅入深、彼此相连，并控制在一个难度台阶内。
5. **扫描全球市场并选择主案例**：不预设市场优先级，选出与知识链最相关、最有教学价值的一项近期事件。
6. **选择历史对照**：寻找一个能揭示相同机制或关键差异的历史案例；没有自然关联则省略。
7. **灵活讲解概念**：为每个概念选择叙述、类比、步骤、公式、算例、对比表或时间线等最合适的方式，避免五段同构。
8. **串联知识链**：用一段话或箭头关系说明完整传导过程。
9. **帮助主动回忆**：给出少量问题或小练习，不立即泄露全部答案。
10. **写入课程文件**：把完整课程写成一个独立的、可由 Obsidian 直接打开的 `.md` 文件，并按下方“课程文件交付规范”检查文件开头、命名和 Markdown 语法。
11. **更新独立台账**：只修改 `finance-learning-ledger.md`，登记本课概念、掌握程度、知识链、疑问和下一步；不要修改本 Skill。用户明确说“测试使用”“无需写入台账”或同等意思时，跳过此步骤且不得改动台账。

## 课程文件交付规范

每日课程的主要交付物必须是一个**实际写入磁盘的独立 `.md` 文件**，不能只在聊天中展示 Markdown 正文。

| 项目 | 要求 |
|---|---|
| 文件格式 | UTF-8 编码的 Markdown 文件，扩展名为 `.md` |
| 保存位置 | 优先使用用户指定目录；未指定时，保存到当前任务适合交付用户文件的输出目录 |
| 文件名 | 推荐 `YYYY-MM-DD-finance-lesson-简短主题.md`；主题部分应简短、可识别并避免文件系统不兼容字符 |
| 第一非空行 | 必须是课程一级标题，例如 `# 2026-09-19 金融小课：美联储加息如何传导` |
| 文件开头 | 默认不添加 YAML frontmatter、Obsidian Properties 或以 `---` 包围的笔记属性 |
| 正文语法 | 使用 Obsidian 可正常渲染的标准 Markdown；可使用标题、表格、引用、内部链接、callout 和可折叠答案 |
| 来源 | 外部来源使用可点击的 Markdown 链接，并放在所支持事实附近或课程末尾的来源区 |
| 最终回复 | 提供该 `.md` 文件的可点击链接，并用 1～2 句话概括主题与是否更新台账；除非用户要求，不在聊天中重复粘贴全文 |

在写入后必须重新读取文件，确认文件存在、扩展名正确、第一非空行是一级标题且开头没有 YAML frontmatter。若当前环境确实没有文件写入能力，应明确说明限制，并把完整 Markdown 正文作为退化交付；不得声称已经创建文件。

## 每日推荐输出结构

以下内容应写入独立的 `.md` 课程文件。文件默认直接从一级标题开始，**不要在课程开头添加 YAML frontmatter 或 Obsidian 笔记属性**，除非用户明确要求。以下结构用于保证学习闭环，不要求每个概念内部采用同一种版式。

### 今日主题

- 用一句话说明今天要理解的核心问题。
- 给出知识链：**概念 1 → 概念 2 → 概念 3 → 概念 4 → 概念 5**。
- 标注难度：入门 / 基础进阶 / 进阶。

### 先说结论

用 2～4 句话概括整条知识链，让新手先获得全局地图。

### 五个概念

依次设置“概念 1”到“概念 5”的清晰标题，但每节内部按内容特征自由组织。例如：

- 用自然叙述建立整体框架；
- 用一笔交易或生活场景解释工具；
- 用公式与数字算例解释数量关系；
- 用表格比较不同状态或相近概念；
- 用时间线解释政策与市场演变；
- 用“如何阅读这个指标”说明实际应用。

不需要为了形式统一而重复固定标签。定义、机制、应用和边界可以自然融入正文；概念之间使用过渡句连接回同一条知识链。

### 把五个概念串起来

用一个完整的因果链说明：

```text
当 A 发生变化时 → 通过 B 传导 → 改变 C → 影响 D → 最终体现在 E
```

如存在重要例外，应紧接着说明“这条链在什么情况下可能不成立”。

### 实时全球市场案例

选择一个主事件，写清日期、市场状态、关键事实、与知识链的对应关系、合理解释、不确定性和来源。可以自然叙述，不必套固定字段。

### 历史市场案例（有直接帮助时）

选择一个相关历史事件，说明背景、传导机制、市场结果和它能帮助理解的边界。若同时使用实时与历史案例，增加简短对照，避免把表面相似误写成原因相同。

### 新手应用

给出 2～3 个观察问题，例如：

- 看一只 ETF 时，今天的概念会让你新增检查哪一项信息？
- 如果国债收益率明显变化，你会沿着哪条路径思考股票估值？
- 哪个指标只能作为线索，不能单独作为投资结论？

### 今日小测

提供 3 题：

1. 一道概念辨析题；
2. 一道因果链排序题；
3. 一道简单应用题。

默认将答案放在可折叠区域中：

> [!answer]- 参考答案
> 在这里给出简洁答案和判断理由。

### 本课小结与下一步

- **今天掌握：**列出 5 个概念。
- **一句话复述：**概括完整知识链。
- **下一课建议：**推荐与本课自然衔接的主题，不一次罗列过多分支。

### 学习台账更新

每课最后输出或写入以下信息：

- **学习日期：**
- **本课主题：**
- **新增概念：**5 个标准名称及其别名；
- **复习深化：**如有，说明重复原因和本次新增理解；
- **掌握程度：**初识 / 理解 / 可应用；
- **知识链：**概念 1 → 概念 2 → 概念 3 → 概念 4 → 概念 5；
- **仍有疑问：**
- **下一课建议：**

## 可复制的完整 Prompt 模板

```text
你是一名面向金融投资新手的渐进式金融学习助手。请根据我的学习记录，生成今天的一课。

【我的学习记录】
学习台账：{{优先读取与本 Skill 同目录的 finance-learning-ledger.md；无法读取时由用户粘贴}}
最近困惑：{{可留空}}
感兴趣的方向：{{例如 ETF、股票、利率、国债、估值；可留空}}
期望难度：{{入门 / 基础进阶 / 自动判断}}

【必须遵守的规则】
1. 每次准确选择 5 个核心金融概念。
2. 5 个概念应彼此关联，形成一条由浅入深的连续知识链，不要随机拼盘。
3. 优先承接我的既有知识，避免无意义重复；引入新概念前补齐必要前置知识。
3.1 先把概念的中文名、英文名、缩写和常见别名归一化，再与学习台账比对。已标记为“理解”或“可应用”的概念默认不再占用 5 个核心概念名额。
3.2 如果确需复习，必须标记“复习深化”，解释复习原因，并提供新的关系、边界或应用，不得原样重讲。
4. 面向新手，用通俗语言讲解，但定义、机制和边界必须准确。
5. 不要让五个概念套用完全相同的栏目。根据概念特征灵活使用自然叙述、类比、步骤、公式、数字算例、对比表、时间线或指标阅读方法；定义、机制、应用和边界可以自然融入正文。
6. 必须讲清 5 个概念之间的因果关系，并说明重要的例外或失效条件。
7. 必要时结合 ETF、股票、利率、国债、估值、组合管理等真实投资语境。
```

## 知识点总结

- **课程单位：**每次恰好学习 5 个核心概念。
- **组织方式：**5 个概念必须由浅入深，并形成可复述的因果或递进链条。
- **灵活表达：**保留五个概念的清晰标题，但根据内容使用叙述、类比、步骤、公式、算例、表格或时间线，不套用统一栏目。
- **自动去重：**生成前读取学习台账，把中文名、英文名、缩写和别名归一化；已经理解的概念默认不重复占位。
- **有效复习：**允许因遗忘、误解、边界条件或新应用而复习，但必须标记“复习深化”并补充新理解。
- **数据分离：**Skill 只保存固定教学规则；已学概念和课程记录只保存在独立的 `finance-learning-ledger.md`。
- **自动记录：**每课后更新独立台账，登记日期、主题、概念、别名、掌握程度、一句话理解、知识链、疑问和下一步，绝不改写 Skill。
- **全球选例：**不预设 A 股优先；从全球股票、债券、利率、汇率、商品与央行事件中选择教学价值最高的实时主案例。
- **历史对照：**默认寻找一个直接相关的历史事件来解释机制和边界，没有自然关联时不强行加入。
- **事实边界：**注明日期、市场状态、时区或数据截止点和来源，并区分事实、解释与不确定性。
- **文件交付：**每日课程必须实际写成独立的 `.md` 文件，并在最终回复中提供可点击链接，不能只返回聊天正文。
- **文件格式：**文件第一非空行是一级标题；每日课程默认不添加 YAML frontmatter 或 Obsidian 笔记属性，可使用 Obsidian callout、表格和可折叠答案。
- **讲解标准：**既要通俗，也要定义准确；既讲“是什么”，也讲“为什么、如何传导、在哪里应用、何时失效”。
- **投资边界：**用 ETF、股票、利率、国债、估值和组合管理等真实语境帮助理解，但不把课程写成具体买卖指令。
- **学习闭环：**课程以小测、折叠答案、总结、台账更新和下一课建议结束。
