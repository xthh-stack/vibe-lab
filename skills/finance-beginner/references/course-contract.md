# 渐进式金融小课课程契约

## 目标

面向中文金融投资新手，每次围绕一个清晰主题讲解**恰好 5 个核心概念**，并把它们串成一条由浅入深、可以复述的知识链。课程既要解释“是什么”，也要解释“为什么、如何传导、在哪里应用、何时可能失效”。

## 学习成果

每课帮助用户：

1. 准确理解 5 个概念的定义；
2. 看懂概念之间的因果或递进关系；
3. 知道概念在 ETF、股票、利率、国债、估值或组合管理中的用途；
4. 用自己的话复述知识链，并完成简单应用。

## 概念选择

- 每次只选恰好 5 个核心概念，不用同义词或细小组成部分凑数。
- 辅助术语可以简短解释，但不占核心概念名额。
- 概念应形成连续链条，例如：

```text
前置条件 → 传导机制 → 资产影响 → 估值结果 → 投资应用
```

- 清楚解释前一个概念如何引出后一个概念，以及关系在什么条件下会减弱、反转或暂时失效。
- 优先从用户已知内容向外扩展，每次只提高一个合理难度台阶。
- 用户没有学习记录时，从最基础且最常用的概念开始。

## 学习台账与去重

个人学习进度只保存在 `finance-learning-ledger.md`，不得写回 `SKILL.md` 或本课程契约。

开课前：

1. 读取概念索引、最近课程、当前疑问和下一课建议；
2. 把中文名、英文名、缩写与常见别名归一化后再去重；
3. 标记为“理解”或“可应用”的概念默认不再占用五个核心概念名额；
4. 标记为“初识”的概念可以复习深化，但必须说明复习原因，并增加新的关系、边界或应用；
5. 用户主动要求复习时可以重复，但不能原样重讲。

结课后，只更新台账：

- 日期与课程主题；
- 5 个概念的标准名称、别名、掌握程度与一句话理解；
- 完整知识链；
- 复习深化原因；
- 仍有疑问与下一课建议；
- 市场案例及数据日期。

只有课程、小测或用户反馈提供证据时，才提高掌握程度。技能升级、迁移和重新安装不得删除或重置台账。用户明确说“测试使用”“无需写入台账”或同等意思时，不得修改任何台账。

## 市场案例与事实核验

选择案例前，先观察与知识链相关的全球市场：

- A 股、港股、美股、欧洲、日本等股票市场；
- 国债、信用债、货币市场；
- 利率、汇率、原油、黄金与其他重要商品；
- 主要央行政策、宏观数据与具有广泛影响的公司事件。

不要预设 A 股优先。从全球市场选择一个因果链清楚、可靠数据充分且最有教学价值的实时主案例，不堆砌新闻。

凡涉及当天、近期或“最新”：

1. 必须联网核验，不能凭记忆填写数字；
2. 先判断市场处于盘前、盘中、收盘或休市；
3. 盘中数据注明北京时间或当地时间与截止时点，休市时使用最近完整交易日；
4. 优先引用央行、统计机构、交易所、监管文件、公司公告与基金官网，必要时补充 Reuters、AP 等可靠通讯社；
5. 把来源放在所支持事实附近，并保留完整 URL；
6. 明确区分“已确认事实”“基于事实的合理解释”和“仍不确定”；
7. 不把同时发生或相关性写成唯一因果。

默认寻找一个直接相关的历史案例，用于说明相同机制、关键差异或失效边界。没有自然关联时可以省略，不强行加入历史案例。若同时使用实时与历史案例，用简短对照解释背景、传导机制、市场信号与结果的异同。

## 讲解方式

首次出现的缩写同时给出中文名、英文全称与缩写，例如：

> 市盈率（Price-to-Earnings Ratio，PE）

根据概念特点灵活选择表达方式：

- 机制型概念使用因果叙述；
- 交易工具使用步骤或具体场景；
- 数量概念使用公式与数字算例；
- 相近概念使用对比表；
- 历史变化使用时间线；
- 抽象概念使用准确但不过度简化的类比。

五个概念保留清晰标题，但不要机械重复相同的小栏目。使用公式时先解释变量和直觉，再展示公式。

优先使用以下真实语境：

- ETF：指数跟踪、费用、成分股、行业与地区暴露、持仓重叠；
- 股票：盈利、现金流、估值、流通盘、市场预期；
- 利率与国债：政策利率、收益率、期限、债券价格、风险偏好；
- 估值：盈利、现金流、增长、折现率、安全边际；
- 组合管理：仓位、相关性、集中度、波动与回撤。

## 课程结构

完整课程写入独立的 `.md` 文件，按以下顺序组织：

1. 一级标题；
2. 今日主题；
3. 知识链；
4. 难度：入门 / 基础进阶 / 进阶；
5. 先说结论；
6. 五个概念；
7. 把五个概念串起来；
8. 实时全球市场主案例；
9. 历史案例与对照（有直接帮助时）；
10. 新手应用；
11. 今日小测与答案；
12. 本课小结与下一步。

### 今日主题

用一句话说明核心问题，列出五概念知识链并标注难度。

### 先说结论

用 2～4 句话给出全局地图。

### 五个概念

依次设置五个清晰标题。定义、机制、应用和边界自然融入正文，并用过渡句接回知识链。

### 把五个概念串起来

给出完整传导链，例如：

```text
当 A 发生变化时 → 通过 B 传导 → 改变 C → 影响 D → 最终体现在 E
```

紧接着说明重要例外或失效条件。

### 实时全球市场案例

写明日期、市场状态、关键事实、知识链对应关系、合理解释、不确定性和来源。

### 历史市场案例

仅在有直接帮助时加入，解释背景、机制、结果与对理解边界的价值。

### 新手应用

给出 2～3 个观察问题，帮助用户把概念用于阅读 ETF、指数、利率或公司信息，但不替用户作交易决定。

### 今日小测

提供三题：

1. 概念辨析题；
2. 因果链排序题；
3. 简单应用题。

答案默认放在 Obsidian 可折叠区域：

```markdown
> [!answer]- 参考答案
> 简洁答案与判断理由
```

### 本课小结与下一步

- 今天掌握：列出 5 个概念；
- 一句话复述：概括完整知识链；
- 下一课建议：推荐一个自然衔接的主题。

课程结尾保留一句：

> 本文仅用于金融知识学习，不构成投资建议。

## 文件交付规范

| 项目 | 要求 |
|---|---|
| 文件格式 | UTF-8 Markdown，扩展名 `.md` |
| 保存位置 | 优先使用用户指定目录；否则使用当前任务适合交付文件的输出目录 |
| 文件名 | 推荐 `YYYY-MM-DD-finance-lesson-简短主题.md`，避免不兼容字符 |
| 第一非空行 | 必须是课程一级标题 |
| 文件开头 | 默认不添加 YAML frontmatter 或 Obsidian Properties，除非用户明确要求 |
| 正文语法 | 使用 Obsidian 可渲染的标准 Markdown，可使用表格、内部链接、callout 和折叠答案 |
| 来源 | 使用可点击 Markdown 链接，靠近所支持事实或放入来源区 |
| 最终回复 | 提供课程文件链接，概括主题并说明台账是否更新；除非用户要求，不重复全文 |

写入后重新读取文件，确认它存在、扩展名正确、第一非空行是 H1、没有意外 frontmatter、恰好包含五个核心概念、来源完整且小测存在。没有文件写入能力时，明确说明限制并把完整 Markdown 作为退化交付，不得声称已经创建文件。

## 投资与表达边界

- 不给出具体证券的买入、卖出、抄底、止损、目标价、仓位比例或收益保证；
- 不把课程改写成针对个人情况的投资、税务或法律建议；
- 不用单日涨跌证明长期趋势；
- 不把媒体推测写成公司或政策事实；
- 分析投资标的时列出假设、风险与不确定性；
- 解释指标只能提供线索，不能单独构成结论。
